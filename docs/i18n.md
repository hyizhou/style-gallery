# 多语言 · 设计记录

> 站点中英双语言的接入设计。当前设计状态描述，不含变更历史。

## 语言与路由

- 中文为默认语言，路径无前缀（`/`、`/styles/x`…）；英文挂在 `/en` 前缀下（`/en`、`/en/styles/x`…）。
- 同一内容的两条路径互为 hreflang 替代；`x-default` 指向中文版。
- 路由表在 `src/App.tsx` 平铺两份（zh 与 /en 前缀），页面组件按路径自行判定语言。

## 判定机制（src/i18n.ts）

- `useLocale()`：从当前路由路径判定 `'zh' | 'en'`——无 Context、无副作用，客户端渲染与静态预渲染共用同一判定。
- `localeBase(locale)`：当前语言的路由前缀，站内链接统一用它拼接。
- `swapLocalePath(pathname)`：语言切换按钮的目标路径，保持当前页面只换语言。
- `useT()`：UI 词典（站点框架与页面固定文案，zh / en 两份）。
- `groupEn` / `heatEn`：数据字段中的中文枚举（分组、热度）到英文显示名的映射。

## 文案分层

| 层 | 位置 | 形态 |
| --- | --- | --- |
| 站点框架与页面固定文案 | `src/i18n.ts` | UI 词典，`useT()` 取用 |
| 数据词条（风格/布局/弹窗/场景/搭配） | 各 `src/data/*.ts` | 条目内 `i18n: { en: { … } }` 字段，与中文原文同处 |
| 演示组件（21 个布局/弹窗 Demo、DemoKit、Signature、M3/Ant 套件） | 组件文件顶部 | 内嵌 `const L = { zh: {…}, en: {…} }`，`L[useLocale()]` 取用 |
| 共享组件（PromptCard 等） | 组件内 | 走 UI 词典 |

- 词条名的英文版直接使用数据自带的 `en` 字段；提示词卡片本身已含 zh/en 变体，英文页默认选中 English 版。
- 英文别名词典随 `i18n.en.aliases` 提供，主页搜索在对应语言下同时命中两种语言的别名。

## SEO（src/data/seo.ts + scripts/prerender.mjs）

- `PageMeta` 含 `locale` 与 `alternates: { zh, en }`；每个中文页面都有对应的 `/en` 页面，反之亦然。
- 预渲染输出按语言的 canonical、`og:locale`（zh_CN / en_US）、`og:site_name` 与三条 hreflang link（zh / en / x-default）。
- 英文页面注入 `<html lang="en">`（模板默认 `zh-CN`）。
- `sitemap.xml` 每个 URL 附 `xhtml:link` 交替链接。

## 翻译约定

- 内容翻译为全文重写，不做机直译；术语与词条名以 `en` 字段为准。
- 英文文案中的撇号使用排版弯引号（’），避免与单引号字符串定界冲突。
